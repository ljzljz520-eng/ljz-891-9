# 品牌经销资质查询系统

客户输入经销商名称和门店编号，即可查询授权品牌、区域、有效期、上级代理和开通时间。后台支持多管理员维护资质，支持 CSV 批量导入，并可发送资质确认邮件。

## 功能特性

### 客户端
- 🔍 **公开查询**：输入经销商名称 + 门店编号，返回授权品牌、授权区域、有效期、上级代理、开通时间
- 📱 响应式设计，支持手机/电脑访问

### 管理后台
- 👥 **多管理员**：超级管理员可创建/禁用/删除管理员，分配角色
- 🏪 **经销商管理**：经销商 CRUD，支持搜索、筛选、分页
- 📜 **授权资质管理**：每个经销商可维护多个品牌授权（品牌、区域、有效期、状态）
- 📥 **CSV 批量导入**：下载模板，批量导入经销商及授权，支持 upsert/insert 两种模式
- 📋 **查询日志**：记录所有公开查询，支持按名称/编号/结果筛选
- ✉️ **邮件通知**：一键发送资质确认邮件给经销商，支持 SMTP 测试
- 📊 **数据概览**：经销商数、授权数、查询趋势统计

## 快速开始

```bash
# 安装依赖
npm install

# 复制配置文件
cp .env.example .env

# 启动（默认使用 SQLite，无需配置数据库）
npm start
```

访问 http://localhost:3000/

管理后台：http://localhost:3000/admin ，初始账号 `admin` / `admin123`
